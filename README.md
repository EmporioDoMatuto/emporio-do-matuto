# Empório do Matuto — catálogo online

Site estático, sem servidor e sem banco de dados.

## Estrutura
- `index.html` — página principal
- `styles.css` — visual
- `script.js` — catálogo, busca e filtros
- `assets/logo.png` — logo extraída do PSD enviado

## Como editar produtos
Abra `script.js` e altere o array `products`.

## Como publicar gratuitamente
Pode ser publicado em GitHub Pages, Netlify ou Cloudflare Pages.
